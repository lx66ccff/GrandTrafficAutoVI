# Roadmap

This roadmap is exploratory and will change as the project gains contributors and validated use cases.

## Milestone 0.1 — Project definition

- [x] Create repository and initial documentation
- [x] Define project scope and terminology
- [ ] Agree on first scenario and measurable success criteria
- [ ] Specify units, coordinate conventions, and scenario format

## Milestone 0.2 — Minimal simulation prototype

- [ ] Implement a directed road graph
- [ ] Add a basic vehicle-agent model
- [ ] Implement route planning
- [ ] Add deterministic simulation tests
- [ ] Export simulation metrics

## Milestone 0.3 — Visualization

- [ ] Define a stable replay or state-stream format
- [ ] Build a simple 2D/3D viewer
- [ ] Evaluate an optional Unreal Engine visualization adapter
- [ ] Document performance and fidelity limitations

## Milestone 0.4 — Experiments

- [ ] Add configurable traffic scenarios
- [ ] Add benchmark and regression datasets
- [ ] Explore GPU acceleration only where profiling demonstrates a benefit
- [ ] Evaluate optional interoperability with external simulation tools

## Long-term directions

- Multi-agent behavior experiments
- Larger road networks and demand models
- Scenario authoring tools
- Reproducible benchmark suite
- Community-maintained adapters
